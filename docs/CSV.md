# memoma3 CSV 仕様

オブジェクト一覧画面からエクスポートする CSV ファイルの仕様を定義します。

## 1. 概要

- **形式**: RFC 4180 準拠の CSV（カンマ区切り）。
- **エンコーディング**: UTF-8（**BOM 付き**）。Excel で正しく開けるよう、ファイル先頭に `\uFEFF`（UTF-8 BOM）を付与します。
- **改行**: 各行の末尾に改行（`writeln`）を付与します。
- **出力元**: `lib/views/object_list_screen.dart` の `_buildCsv`。
- **保存**: `StorageService.saveCanvas`（`file_picker`）で、拡張子 `csv` のファイルとして保存します。ファイル名はキャンバス名を使用します。

## 2. 列定義

ヘッダ行（1 行目）は以下の 11 列です。

| # | ヘッダ | 内容 | 元フィールド | 備考 |
| --- | --- | --- | --- | --- |
| 1 | 名称 | メモのラベル（見出し） | `NoteObject.label` | |
| 2 | 説明 | メモの説明 | `NoteObject.detail` | |
| 3 | 詳細 | メモの本文 | `NoteObject.content` | |
| 4 | 形状 | 形状の日本語名 | `NoteObject.shape.displayName` | 例: 角丸四角 / 楕円 / 六角形 |
| 5 | 強調 | 強調レベルの日本語名 | `NoteObject.emphasis.displayName` | 標準 / 強調 / 弱め |
| 6 | 色 | 本体色（16 進） | `NoteObject.color` | `#RRGGBB` 形式（大文字） |
| 7 | グループ | 属するグループ名 | `GroupFrame.name` | 複数ある場合は ` / ` で連結 |
| 8 | 接続(from) | 発端になっている接続先の名称 | `Connection.sourceId` → 対象メモ | 複数ある場合は ` / ` で連結 |
| 9 | 接続(to) | 着地になっている接続元の名称 | `Connection.targetId` → 対象メモ | 複数ある場合は ` / ` で連結 |
| 10 | X | 位置 X 座標 | `NoteObject.position.dx` | 整数（`toStringAsFixed(0)`） |
| 11 | Y | 位置 Y 座標 | `NoteObject.position.dy` | 整数（`toStringAsFixed(0)`） |

### 2.1 列の補足

- **グループ（#7）**: オブジェクトが属する全グループの名称を列挙します。グループ名が空の場合はグループ ID を使用します。複数グループに属する場合は ` / `（スペース・スラッシュ・スペース）で連結します。
- **接続(from)（#8）**: このオブジェクトが `sourceId` になっている接続の、対象（`targetId`）メモの名称を列挙します。対象メモの名称が空の場合はメモ ID を使用します。
- **接続(to)（#9）**: このオブジェクトが `targetId` になっている接続の、発端（`sourceId`）メモの名称を列挙します。発端メモの名称が空の場合はメモ ID を使用します。
- **X / Y（#10, #11）**: キャンバス座標系の位置を整数（小数点以下切り捨て）で出力します。

## 3. エスケープ規則

`_csvEscape` により、以下のいずれかの文字を含むフィールドは、ダブルクォート（`"`）で囲まれ、内部のダブルクォートは 2 つ（`""`）にエスケープされます。

- カンマ（`,`）
- ダブルクォート（`"`）
- 改行（`\n`）
- 復帰（`\r`）

```text
例:  名前,説明
     "東京, 大阪","彼は""良い""と言った"
```

## 4. 色の形式

`_colorToHex` により、`Color` を `#RRGGBB` 形式（大文字 16 進）に変換します。アルファ値は含めません。

```text
例:  #FF5733, #000000, #FFFFFF
```

## 5. 出力例

```csv
名称,説明,詳細,形状,強調,色,グループ,接続(from),接続(to),X,Y
アイデアA,最初のメモ,詳細テキスト,角丸四角,標準,#FF5733,グループ1,アイデアB,,120,340
アイデアB,2番目のメモ,別テキスト,楕円,強調,#3366FF,グループ1,,アイデアA,560,340
```

## 6. 注意事項

- オブジェクトが 1 つもない場合、エクスポートは行われず SnackBar で「エクスポートするオブジェクトがありません」と表示されます。
- 行の順序は、一覧画面で表示されている（ソート・フィルタ適用後の）順序ではなく、`CanvasState.objects` の登録順（Z 順）で出力されます。
- 接続線・グループ自体の属性（線種・形状・色など）は CSV には含まれません。オブジェクトの属性と、そのオブジェクトに関連するグループ名・接続先名のみを出力します。
