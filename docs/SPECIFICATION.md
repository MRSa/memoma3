# memoma3 機能仕様書

## 1. 概要

memoma3 は、無限キャンバス上にメモ（オブジェクト）を自由に配置・編集し、オブジェクト同士を接続線やグループ枠で関連づけて、アイデアや計画を可視化するデスクトップ / Web / モバイル アプリです。

- **開発言語**: Flutter (Dart)
- **状態管理**: Riverpod 3.x
- **対応プラットフォーム**: Windows / Web / Android
- **テーマ**: Material 3（ダークテーマ、シードカラー `blueGrey`）

## 3. 機能詳細

### 3.1 無限キャンバス

- `InteractiveViewer`（`TransformationController` 付き）でパンとズームを実現。
- キャンバスは `50000 × 50000 px` の `Stack` として構成。
- ズーム倍率は `0.1`〜`5.0`。
- 左下のズーム制御パネルで「縮小 / 拡大 / リセット」が可能。
- 初回表示時にキャンバスの中心を画面中央に配置する。

### 3.2 オブジェクト（メモ）

#### 追加

- キャンバス上の**ダブルタップ**または**長押し**で、その位置に新しいオブジェクトを追加。
- 追加位置は現在の拡大率・移動オフセットを考慮してキャンバス座標に変換される。
- 新規オブジェクトの既定値: サイズ `180×120`、色 `0xFFFFF8DC`（クリーム色）、本文 `メモ`、形状は最後に選択した形状（初回は四角）。

#### 選択

| 操作 | 結果 |
| --- | --- |
| 通常タップ | 全選択を解除し、タップしたオブジェクトのみを選択（単一選択） |
| 同じオブジェクトを再タップ | 選択を解除 |
| Ctrl + タップ | そのオブジェクトの選択をトグル（追加/解除）、他の選択は維持（複数選択） |
| ドラッグ開始 | 全選択を解除し、ドラッグしたオブジェクトのみを選択 |

#### 選択モード（キーボードのない環境向け）

キーボードが接続されていない環境（Android 等）では Ctrl+タップが使えないため、上部バーの「選択モード」ボタンで選択モードを有効にすると、タップのみで複数選択できる。

| 操作 | 結果 |
| --- | --- |
| 「選択モード」ボタン | 選択モードを有効/無効に切替（接続モードと排他） |
| オブジェクトをタップ | そのオブジェクトの選択をトグル（追加/解除）、他の選択は維持 |
| 空き領域をタップ | 全選択を解除 |
| 「全選択」ボタン | 全オブジェクトを選択（選択モード中かつオブジェクトがあるときのみ有効） |
| 「選択モード」ボタン（再度） | 選択モードを終了（選択状態は保持） |

選択モード中は、オブジェクトのドラッグ移動・空き領域のダブルタップ/長押しによる新規作成は行われない（誤操作防止）。

#### 移動

- ドラッグで移動。移動量は現在の拡大率で割られるため、ズーム状態に関係なく自然に追従。
- ドラッグ中はローカル表示座標が即座に更新され、`PanEnd` 時に実オブジェクトへ反映・Undo 履歴へ保存される。

#### 編集

選択中のオブジェクトをダブルタップ / 長押し、または上部バーの「編集」ボタンで編集ダイアログを表示。以下を変更可能:

- **形状**: 角丸四角・四角・楕円・円・正方形・平行四角形・台形・六角形・五角形（4 方向）
- **ラベル**: 見出しテキスト
- **詳細**: 本文テキスト（複数行）
- **本文**: 説明テキスト（複数行）
- **色**: 本体色（`flex_color_picker`）
- **ラベル色**: ラベルテキストの色
- **説明色**: 説明テキストの色
- **強調**: 標準 / 強調 / 弱め

形状を選択すると、次回新規作成時のデフォルト形状として保持される。

#### 削除

- **削除**: 選択中のオブジェクトを削除（複数選択時は全選択分）。接続線・グループ枠も連動して整理される。
- **全削除**: 全オブジェクト・接続線・グループ枠を削除（確認ダイアログ付き）。

### 3.3 整列

- **単一選択**: X / Y 座標を 10 の倍数に整列。
- **複数選択**: 整列方法を選択するダイアログを表示。
  - **左揃え**: 一番左の左端を 10 の倍数に整えて全 X を揃える。
  - **右揃え**: 一番右の右端を 10 の倍数に整えて全 X を揃える。
  - **上揃え**: 一番上の上端を 10 の倍数に整えて全 Y を揃える。
  - **下揃え**: 一番下の下端を 10 の倍数に整えて全 Y を揃える。
  - **等間隔（横幅）**: 左右の端を基準に X 方向で等間隔に配置。
  - **等間隔（縦幅）**: 上下の端を基準に Y 方向で等間隔に配置。

### 3.4 接続線

2 つのオブジェクトを線で接続する機能。線には線種（`LineType`）・形状（`LineShape`）・色を設定できる。

#### 操作方法

- **ドラッグで接続**: 「接続モード」ボタンで有効化。接続モード中、オブジェクトをドラッグして別のオブジェクトまで移動すると接続線が追加される。
- **選択状態での接続**: 複数オブジェクトを選択して「接続」ボタンを押すと、選択中の全ペアに接続線が追加される。
- **線種・形状・色の切替**: 接続線をタップしてコンテキストメニューを表示し、切り替え可能。
- **接続解除**: コンテキストメニューの「接続線を解除」で削除。

#### 線種（LineType）

| 線種 | 説明 |
| --- | --- |
| 通常の線 | 標準の細線 |
| 太線 | 太い線 |
| 点線 | 点線 |
| 一点鎖線 | 一点鎖線 |

#### 形状（LineShape）

| 形状 | 説明 |
| --- | --- |
| 矢印 | 終点に矢印頭を持つ直線 |
| 直線 | 始点と終点を直線で結ぶ（デフォルト） |
| カギ線 | 直角に折れ曲がるカギ線 |
| 曲線 | 三次ベジェ曲線 |
| 両方向矢印 | 両端に矢印頭を持つ直線 |
| 逆矢印 | 始点側に矢印頭を持つ直線 |

接続線はオブジェクトが移動しても追従して描画される。

### 3.5 グループ化

複数のオブジェクトを矩形の枠で囲み、枠まとめて扱う機能。

- **作成**: 複数オブジェクトを選択して「グループ化」ボタンを押すと、選択中の全オブジェクトを囲むグループ枠が作成される。
- **枠での移動**: グループ枠上をドラッグすると、枠に属する全オブジェクトが同時に移動する。
- **編集**: グループ枠を長押しして名称・説明・色を変更可能。
- **メンバー追加**: グループ枠にオブジェクトを追加可能。
- **削除**: グループ枠を削除可能（メンバーオブジェクトは残る）。

### 3.6 Undo / Redo

- **Undo**: 1 つ前の状態に戻す。履歴は最大 30 件。
- **Redo**: Undo で退避した状態を復元する。
- 新しい操作を行うと Redo 履歴はクリアされる。
- ドラッグ操作は `PanEnd` 時にのみ履歴へ保存される（ドラッグ中は履歴に積まない）。

### 3.7 保存 / 読み込み

- **保存**: キャンバス状態（オブジェクト・接続線・グループ枠）を JSON として保存。
  - Windows / Android: `file_picker` の `saveFile` で保存先を選択。
  - Web: ブラウザダウンロード。
- **読み込み**: JSON を読み込んでキャンバス状態を復元。
  - Windows / Android: `file_picker` の `pickFiles` でファイルを選択。
  - Web: ブラウザアップロード。
- 読み込み時に接続線 ID・グループ ID の重複を自動解消する。

### 3.8 画像 / PDF エクスポート

- キャンバス状態（オブジェクト・接続線・グループ枠・背景）を PNG / PDF として書き出し。
- ヘッダーにアプリのアイコンとキャンバス名称を表示。
- 出力サイズは全オブジェクトの外接矩形に上下左右 25px のマージンを持たせた必要最小限の大きさ。
- 背景色・背景画像は出力全体に描画（グリッドは出力しない）。

### 3.9 オブジェクト一覧

全オブジェクトを表形式で一覧表示する画面。

- **表示カラム**: No. / 名称 / 説明 / 詳細 / 形状 / 強調 / 色 / グループ / 接続(from) / 接続(to) / X / Y / 中心移動 / 削除
- **フィルタ**: 名称（テキスト）・形状（複数選択）・強調（複数選択）
- **ソート**: カラムヘッダのタップで並べ替え
- **直接編集**: 名称・説明・詳細・形状・色・強調・X/Y 座標をテーブル上で編集
- **中心移動**: 行のボタンでキャンバス中心に移動
- **削除**: 行のボタンで削除（確認ダイアログ付き）
- **新規追加**: キャンバス中心にオブジェクトを追加
- **CSV エクスポート**: Excel で読める CSV（UTF-8 BOM 付き）として書き出し

### 3.10 背景ガイド

キャンバスの背景に以下の要素を独立して設定可能（各要素の透明度を個別調整）。

- **グリッド**: 種類（なし / 罫線 / ドット）・間隔・色・透明度
- **背景色**: 色・透明度
- **背景画像**: ローカル画像の選択・透明度

設定は `shared_preferences` に永続化され、アプリ再起動後も維持される。

### 3.11 キャンバス名

- 上部バー中央に表示。タップで変更ダイアログを表示。
- Enter（改行）で確定し、ダイアログを閉じる。
- 保存時の初期ファイル名・エクスポート時のヘッダー名にも使用。

### 3.12 自動永続化

- キャンバス状態（オブジェクト・接続線・グループ）とキャンバス名を、操作のたびに自動で保存する。
- 保存先はアプリ内部の永続化領域（`hive_ce` の box `memoma3_canvas`）。
- 書き込みはデバウンス（400ms）でまとめ、高頻度のドラッグ更新でも I/O を抑制する。
- アプリがバックグラウンドに移る（終了する）タイミングで未保存データを確実に書き込む。
- 起動時に前回の状態を復元し、アプリを終了して再度起動してもそのままの表示になる。
- 初回起動（保存データなし）は初期状態から始まる。
- 手動の「保存 / 読み込み」（JSON ファイル）は引き続き利用可能（エクスポート・共有用途）。

## 4. 非機能要件

- **状態管理**: 全状態は不変（immutable）モデルで管理し、`copyWith` で複製を作成。
- **Undo 履歴**: 最大 30 件。同一状態の連続プッシュは省略。
- **後方互換性**: 旧形式の JSON ファイルも読み込み可能。
- **クロスプラットフォーム**: Windows / Web / Android で同一のコードベースからビルド。
