# memoma3 操作説明書

memoma3 は、無限キャンバス上にメモ（オブジェクト）を配置し、接続線やグループで整理しながらアイデアを可視化するアプリです。本ドキュメントは、画面の操作手順を説明します。

## 1. 画面構成

```text
┌──────────────────────────────────────────────────────────────┐
│  [読み込み][保存][画像/PDF] │ [Undo][Redo] │ オブジェクト:N  Undo:N │ [キャンバス名✎] │ [整列][接続][編集] │ [削除][全削除] │ [グループ化][接続モード][選択モード][全選択] │ [一覧][背景]   ← 上部アクションバー
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                        キャンバス（無限）                      │
│                                                              │
│              ┌──────────┐        ┌──────────┐                │
│              │  メモ     │───────▶│  メモ     │                │
│              └──────────┘        └──────────┘                │
│                                                              │
│   [−][+] [⊙] 100%                                          ← ズームパネル（左下）
│                                          [操作説明カード]     ← 右下（タップでデバッグ切替）
└──────────────────────────────────────────────────────────────┘
```

- **上部アクションバー**: 全操作の入口。
- **キャンバス**: メモ・接続線・グループ枠を描画する領域。パン（移動）・ズーム（拡大縮小）可能。
- **ズームパネル**（左下）: 縮小 / 拡大 / リセット / ズーム率表示。
- **操作説明カード**（右下）: タップするとデバッグモード（座標表示）が切替わる。

## 2. メモ（オブジェクト）の操作

### 2.1 新規作成

- キャンバスの**空き領域をダブルタップ**または**長押し**すると、その位置に新しいメモが作成されます。

### 2.2 選択

- **タップ**: 1 つのメモを選択（同時に最前面へ移動）。
- **Ctrl + タップ**: 選択をトグル（複数選択）。
- 選択中のメモは四隅の枠線で強調表示されます。

### 2.3 複数選択（選択モード）

キーボードが接続されていない環境（Android 等）では Ctrl+タップが使えないため、**選択モード**でタップのみによる複数選択ができます。

1. 上部アクションバーの**選択モード**ボタン（チェックリスト風アイコン）を押して選択モードを有効にします。
2. 選択したいメモを**タップ**すると、選択が追加/解除されます（他の選択は維持）。
3. 必要に応じて**全選択**ボタンで全メモを選択できます。
4. **選択モード**ボタンを再度押すことで選択モードを終了します（選択状態は保持されます）。

選択モード中の動作:

| 操作 | 結果 |
| --- | --- |
| メモをタップ | 選択をトグル（追加/解除）、他の選択は維持 |
| 空き領域をタップ | 全選択を解除 |
| 全選択ボタン | 全メモを選択 |
| 選択モードボタン（再度） | 選択モードを終了（選択は保持） |

> **注**: 選択モード中は、メモのドラッグ移動や空き領域のダブルタップ/長押しによる新規作成は行われません（誤操作防止）。選択モードと接続モードは同時に有効にできません。

### 2.4 移動

- メモを**ドラッグ**すると移動します。ズーム状態に関係なく自然に追従します。
- ドラッグ終了時に Undo 履歴へ保存されます。

### 2.5 編集

- メモを**ダブルタップ**または**長押し**すると、編集ダイアログが開きます。
- 編集ダイアログで設定できる項目:
  - **ラベル**（見出し）
  - **本文**
  - **説明**
  - **形状**（角丸四角 / 四角 / 楕円 / 平行四角形 / 台形 / 六角形 / 五角形 / 円 / 正方形 など）
  - **強調**（標準 / 強調 / 弱め）
  - **色**（本体色 / ラベル色 / 説明色）

### 2.6 削除

- 1 つ以上のメモを選択し、上部アクションバーの**削除**ボタンを押します。確認ダイアログで承認すると削除されます。
- **全削除**ボタンで、全メモを削除できます（確認ダイアログあり）。

## 3. 接続線の操作

### 3.1 作成（接続モード）

1. 上部アクションバーの**接続モード**ボタン（鉛筆アイコン）を押して接続モードを有効にします。
2. 接続元のメモを**ドラッグ**し、接続先のメモの上で離します。
3. 2 つのメモの間に接続線が作成されます。
4. 接続モードは再度ボタンを押すことで無効になります。

### 3.2 作成（選択して接続）

- 2 つ以上のメモを選択し、上部アクションバーの**接続**ボタンを押すと、選択したメモ同士を接続します。

### 3.3 編集・削除

- 接続線を**タップ**すると、コンテキストメニューが表示されます。
- メニューから線種・形状・色を変更したり、削除したりできます。

### 3.4 線種・形状

- **線種**: 通常の線 / 太線 / 点線 / 一点鎖線
- **形状**: 矢印 / 直線 / カギ線 / 曲線 / 両方向矢印 / 逆矢印

## 4. グループの操作

### 4.1 作成

- 1 つ以上のメモを選択し、上部アクションバーの**グループ化**ボタンを押すと、選択したメモをまとめるグループ枠が作成されます。

### 4.2 編集

- グループ枠を操作すると、グループの編集ダイアログが開きます。
- 名称・説明・枠線の色を設定できます。

### 4.3 移動

- グループ枠を**ドラッグ**すると、枠内のメモがまとめて移動します。

### 4.4 削除

- グループ枠を操作して削除できます。

## 5. 整列

上部アクションバーの**整列**ボタン（中央揃えアイコン）で整列します。

- **1 つ選択時**: 選択したメモの X / Y 座標を 10 の倍数に整列します。
- **複数選択時**: 整列方法を選択するダイアログが表示されます。
  - 左揃え
  - 右揃え
  - 上揃え
  - 下揃え
  - 等間隔（横幅）
  - 等間隔（縦幅）

## 6. 背景ガイド設定

上部アクションバーの**背景ガイド設定**ボタン（ギアアイコン）で設定します。

- **グリッド**: なし / 罫線 / ドット
- **グリッド間隔**
- **グリッドの色・不透明度**
- **背景色・不透明度**
- **背景画像・不透明度**

設定はアプリ再起動後も保持されます。

## 7. キャンバスのパン・ズーム

### 7.1 パン（移動）

- キャンバスの空き領域を**ドラッグ**すると、キャンバスを移動できます。

### 7.2 ズーム（拡大縮小）

- **左下のズームパネル**で操作します。
  - **−**（縮小）: 0.8 倍
  - **+**（拡大）: 1.25 倍
  - **⊙**（リセット）: キャンバス中心を画面中央に移動
- ズーム率は 10%〜500% の範囲で変化します。
- ズームパネルの右端に現在のズーム率（例: `100%`）が表示されます。

## 8. 保存・読み込み

### 8.1 保存

- 上部アクションバーの**保存**ボタンを押すと、ファイル保存ダイアログが表示されます。
- 選択したファイルに、現在のキャンバス状態（メモ・接続線・グループ）が JSON 形式で保存されます。

### 8.2 読み込み

- 上部アクションバーの**読み込み**ボタンを押すと、ファイル選択ダイアログが表示されます。
- 選択した JSON ファイルの内容が現在のキャンバスに読み込まれます。

## 9. 画像 / PDF エクスポート

- 上部アクションバーの**画像/PDF エクスポート**ボタンを押すと、エクスポート形式（PNG / PDF）と保存先を選択できます。
- キャンバス上のメモ・接続線・グループ枠が画像または PDF に書き出されます。

## 10. オブジェクト一覧

上部アクションバーの**オブジェクト一覧**ボタン（表アイコン）で、全メモの一覧画面を開けます。

### 10.1 表示される列

- **左固定パネル**: No. / 名称
- **右スクロールパネル**: 説明 / 詳細 / 形状 / 強調 / 色 / グループ / 接続(from) / 接続(to) / X / Y / 中心移動 / 削除

### 10.2 フィルタ

- **名称**: テキストで絞り込み
- **形状**: 複数選択
- **強調**: 複数選択

### 10.3 ソート

- 列ヘッダをクリックすると、その列で昇降順ソートできます。

### 10.4 中心移動

- 各行の**中心移動**ボタン（⊙）を押すと、そのメモの中心座標がキャンバスの中心に設定されます。

### 10.5 削除

- 各行の**削除**ボタンを押すと、確認ダイアログで承認されたときのみ削除されます。

### 10.6 CSV エクスポート

- 一覧画面から、全メモの属性を CSV ファイルとして出力できます。
- 詳細な仕様は `docs/CSV.md` を参照してください。

## 11. キャンバス名の変更

- 上部アクションバー中央の**キャンバス名**（編集アイコン付き）をタップすると、名前を変更できます。

## 12. Undo / Redo

- **Undo**（元に戻す）: 上部アクションバーの Undo ボタン。最大 30 件まで戻せます。
- **Redo**（やり直す）: 上部アクションバーの Redo ボタン。
- 上部アクションバーには、現在の Undo 可能件数（`Undo: N`）が表示されます。
- ドラッグ操作はドラッグ終了時にのみ履歴へ保存されます。

## 13. デバッグモード

- 右下の**操作説明カード**をタップすると、デバッグモードが切替わります。
- デバッグモード有効時:
  - タップ位置に黄色いインジケーターが表示されます。
  - カーソル座標・タップ座標（スクリーン / ローカル / キャンバス）・可視キャンバス範囲が表示されます。
